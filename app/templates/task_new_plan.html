方案模式说明：纸张/装订/工艺留空 = 由系统从资料库推荐；预算留空 = 不按预算过滤。 系统会枚举有限组合（最多 24 个候选）逐个做规则校验与成本计算，返回最多 3 个可行方案（含预算内/最接近方案），不会让模型猜测价格。

任务信息与基础参数

* 为必填项；其余留白由系统推荐
0 单色；>0 按四色档计印刷/制版费。方案模式不再枚举色数，按此值计算。
预算用于过滤方案；预算内无方案时会给出最接近方案和差额。
取消 创建后进入任务详情，点击“运行 AI 测算”生成候选方案。

方案模式怎么跑

  1. 确定开本 / 印张 / 印数 / 色数（基础参数）
  2. 纸张、装订、工艺可留空（系统推荐）
  3. 填预算（可选）；备注写业务偏好
  4. 运行 AI：先读规则，再由 plan_candidates 枚举组合、真实校验与计算
  5. 结果页出现候选方案表，选一个“采用该方案”生成版本
  6. 提交审核 → 审核员通过/退回（与标准任务一致）

示例

16开 / 12印张 / 3000册 / 四色；纸张、装订留空；预算 15000 元 → 预计给出 3 个可行方案（如 14098 / 14638 / 14828 元）。

规则与资料

方案只从已启用资料库取值；装订/工艺组合必须通过规则库校验；模型不猜价格，候选金额由后端计算。
