一次 AI 测算的真实调用链： POST /api/business-tasks/{id}/ai-tasks（202）→ 后台线程置 RUNNING → 模型选择工具（检索报价/规则 → 校验参数 → 计算成本） → 后端校验并执行工具、逐条落 tool_call_records → 模型输出最终 JSON → 后端做依据校验并写 ai_results → SUCCEEDED / FAILED。 前端 2s 轮询 /api/ai-tasks/{id}，页面实时展示状态、计数与执行记录。

④ 状态流转（与程序一致）
业务任务：
待处理 PENDING → 待审核 PENDING_REVIEW → 完成 COMPLETED
退回 REJECTED → 修改后重新提交
AI 任务：
待执行 PENDING → 运行中 RUNNING → 完成 SUCCEEDED / 失败 FAILED（可重试，新 attempt）
依据校验：
L1 允许集合（本次工具 source_ids ∪ 关联资料 ∪ 规则 ∪ 参数）软标记；L2 存在性（停用/删除→"依据已变更"）；提交时 409
对应程序：app/agent/orchestrator.py（记录/依据）、app/api/ai.py、app/services/{task,version,basis}_service.py 对应表：ai_tasks、tool_call_records、ai_results、result_versions、review_records、business_tasks
