# 10 录屏脚本（3-5 分钟）

> 提交物④"备用录屏" [原文 L81]；用途：网络/模型故障时供教师核查 [原文 L63]。**必须是真实系统运行，不剪辑、不用 PPT 动画冒充**；静态页面不能代替功能验收。
> 版本：`REC-v1.0`（基准日 2026-11-01）；建议总长 **5:00**（可裁到 3:30），1920×1080，含浏览器地址栏与系统时间。
> 录制前必须已完成：`start.bat` 启动、种子数据就位、`LLM_MODE=real`、两账号可登录、`data/app.db` 已备份（TC06 类操作后恢复）。

| S2 | 0:20-2:00 | 预置任务跑 AI + 执行记录 | 模型自主选工具、≥2 类连续调用、同任务 ID | AI 30 核心 |

| S6 | 4:30-5:00 | 历史查询 | 同一 `task_id` 全链路可回查 | AI·记录完整 5 |

## 2 分镜脚本

### S1 0:00-0:20 真实模式自证

| 项 | 内容 |

### S2 0:20-2:00 预置任务真实运行与执行记录

| 项 | 内容 |
|---|---|
| 画面 | 任务列表 → 点 `BT-DEMO-0001` 详情 → 点"运行 AI 测算" → 状态徽标 `PENDING→RUNNING→SUCCEEDED` → 结果区 → 下滚执行记录 |
| 操作 | 1) 任务列表点开基线任务；2) 指参数行（16开/印张 12/3000 册/彩色页 4/胶版纸80g/胶装/覆膜）；3) 点"运行 AI 测算"；4) 等待状态变化（镜头不动，允许 5-10 秒加速**仅限等待空白**，状态变化处必须实时）；5) 指结果 total `14638.00`、单册 `4.88`；6) 展开执行记录，逐条指 `seq`/`tool_name`/`args_json`/`source_ids`/`status`/`latency_ms` |
| 旁白 | "现在让模型自己选工具。它先检索纸张报价，再按规则校验参数，最后调用成本计算。三条记录属于同一个任务 ID，可以看到每次的参数、来源 ID 和耗时 128 毫秒。结果是总成本 14638 元、单册 4.88 元。整个过程是后端执行并写库的，不是前端拼的。" |
| 证据 | 状态徽标变化、≥3 条执行记录、`tool_name` 覆盖 ≥2 类、来源 ID 可见、`business_task_id` 与任务一致 |

### S4 2:40-3:40 版本与越权

| 项 | 内容 |
|---|---|
| 画面 | 版本区：保存人工版本 v2（改 14600.00 + 变更说明）→ 提交审核 → 切到 reviewer 浏览器 → 退回（填意见）→ 回 operator 重提 → reviewer 通过 → 版本列表切 v1/v2 → 最后用 curl 或浏览器请求演示一次越权 403 |
| 操作 | 1) 改总成本为 `14600.00`，变更说明"装订费按新报价"→ 保存人工版本；2) 点提交审核；3) 切 reviewer 窗口刷新，点"退回"，意见填"请复核装订费单价与报价版本"；4) 切回 operator，改说明后重新提交；5) reviewer 点"通过"，状态 `COMPLETED`；6) 版本列表依次点 v1、v2，指 `source=AI/MANUAL`、操作人、时间；7) 打开预置的越权请求卡（`POST /api/business-tasks/1/review`，operator cookie）→ 展示 403 |
| 旁白 | "人工改完保存就是第二个版本，AI 原始版不会被覆盖。提交后审核员可以退回或通过，退回意见必填。现在用操作员身份直接调审核接口——返回 403，权限是后端拦的，不是前端藏按钮。" |
| 证据 | `v1 AI / v2 MANUAL` 两行、退回意见、`COMPLETED`、403 响应体 |
| 注意 | 录制前确认基线任务可退回重提（若已 `COMPLETED`，用 `TASK-B` 或重置演示库） |

## 3 旁白与画面纪律

| 规则 | 说明 |
|---|---|
| 不剪辑 | 只允许对"等待状态刷新"的空白时段做线性加速，且状态变化瞬间必须实时；不得跳切、不得配音替换 |
| 不说未验证的话 | 不说"支持多模型""已通过全部测试"等未核实结论 |
| 不出现假成功 | 失败就展示 `FAILED` 与错误码；不隐藏错误弹窗 |
| 脱敏 | 画面不含真实姓名/学号/手机/邮箱/key/token/内网 IP；截图前确认浏览器无个人信息标签 |
| 时间可见 | 全程保留任务栏时钟，S1 明确指时间（证明录制时间真实性） |
| 标注 | 画面角标常驻"教学模拟数据"；`model_mode` 以页面显示为准 |

## 6 录制后自检（对照"真实调用四层证据"）

- [ ] 第 1 屏出现 `/system` 的 `llm_mode=real`、模型名、`key_configured=true` 与系统时间。
- [ ] 同屏可见"任务 → AI 运行 → ≥2 类工具 → 结果"的连续过程，且状态徽标真实变化。
- [ ] 执行记录逐条可读：`seq`/工具名/参数/结果摘要/来源 ID/状态/耗时。
- [ ] 依据三跳至少完整走 1 条。
- [ ] 存在 ≥2 个可查版本，且能切换对比。
- [ ] 至少一次越权被拒（403/404）与一次失败态（`FAILED`+错误码）。
- [ ] 画面无个人信息与密钥；"教学模拟数据"标注可见。
- [ ] 不剪辑；等待加速处不超过 10 秒且未跨越状态变化。
- [ ] 文件可在离线环境播放（另一台电脑试播成功）。

## 7 兜底话术（现场断网/模型异常时）

| 情况 | 话术 | 动作 |
|---|---|---|
| 断网/模型 401/超时 | "本机刚才真实运行过一次，这是未剪辑录屏与日志；系统内执行记录按任务 ID 可核对。" | 播录屏 + 打开 `logs/app.log` 按 `task_id` grep |
| 模型返回慢 | "本次模型响应慢，系统会在 90 秒上限内结束并给出明确状态。" | 展示 `RUNNING` 与倒计时/超时提示，不掩盖 |
| 任务卡住 | "异常路径也设计了兜底：重启后残留运行会被标记 `STALE_RUNNING`。" | 展示重试与失败记录，不现场改库 |
| 教师临时换参数 | "参数全部走表单，任意合法组合都能跑。" | 现场改纸张/印数重跑，指 `args_json` 变化 |
