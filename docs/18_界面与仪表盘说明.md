# 界面与仪表盘说明（结果格式优化 + 运行仪表盘）

> 2026-11-05 新增的两项低风险体验改进；不改变业务数据、审核、版本等核心逻辑。

## 1 成本测算说明：从“原始 Markdown”改为排版渲染

### 之前
`content_md` 直接以纯文本显示，页面会出现 `## 一、测算口径`、`| 项目 | 金额 |`、`**加粗**` 等原始标记，阅读体验较差。

### 现在
结果页对 `content_md` 做**安全的本地 Markdown 渲染**（不引入外部依赖、不加载 CDN）：

- 标题（`#` / `##` / `###`）分级显示；
- `**加粗**`、`` `代码` ``；
- 无序/有序列表；
- 表格渲染为真正的表格（费用明细、方案对比的可读性明显提升）；
- 分隔线；
- 先做 HTML 转义再渲染，避免内容注入。

同时保留右侧“总成本 / 单册成本”卡片、成本明细表、依据引用、方案候选表；结果区可滚动查看，打印/投屏更整齐。

## 2 运行仪表盘（`/dashboard`）

入口：顶部导航 **仪表盘**（operator / reviewer 登录后可见，只读）。

展示内容：

| 区块 | 内容 |
|---|---|
| 指标卡 | 业务任务总数、AI 运行数、工具调用数、平均 AI 耗时、方案任务数、版本/审核数 |
| 任务状态分布 | 待处理 / 待审核 / 退回 / 已完成（条形图 + 数值） |
| AI 运行状态 | 完成 / 失败 / 运行中 / 待执行 + 成功率 + 平均耗时 |
| 工具调用 Top | 按 `tool_name` 统计真实调用次数 |
| 依据来源 Top | 按 `source_ids_json` 统计被引用最多的资料/规则 ID，可核对真实依据 |
| 最近任务 | 最近 8 条任务，含类型（标准/方案）、状态、创建时间、跳转链接 |
| 验收基线 | BT-DEMO-0001 最新结果（14638.00 / 4.88）与预期基线对照，快速核对真实调用 |

用途：教师现场问“系统整体运行情况/真实调用情况”时，一页即可回答；也便于组内演示前自检。

## 3 其它建议（后续可选，不影响本次提交）

按“投入小、演示收益高”排序：

1. **版本比较**：在任务详情选择两个版本，展示金额/明细/依据 diff（可选功能，价值高）；
2. **按审核意见重新处理**：退回时把审核意见带入任务备注，提供“按意见重跑”入口；
3. **校验试算**：不运行 AI，直接输入参数调用 `validate_spec`，适合演示规则库可运营；
4. **检索/计算效果评测**：固定 benchmark 用例（如 14638/4.88）与实际结果自动比对，仪表盘增加“评测通过率”；
5. **任务列表增强**：搜索高亮、状态筛选记忆、排序、分页控件、批量操作；
6. **结果导出**：Markdown / CSV / 打印 PDF（投屏与归档）；
7. **可访问性与移动端**：键盘操作、对比度、窄屏布局；
8. **审计视图**：把工具执行记录、审核流水按时间线聚合展示。

以上 1–4 项为业务选做方向（任务书明确选做不另加分），可在 11/6 演示后继续；5–8 项为展示/工程增强，风险低但非必需。

## 4 本轮已落地的其它增强（2026-11-05）

| 功能 | 入口/位置 | 说明 |
|---|---|---|
| 纸张下拉 | 新建任务 / 方案模式 / 编辑参数 | 由 `input + datalist` 改为真正的 `<select>`（选项来自资料库），修复“点箭头不弹选项/新装订标红”的浏览器体验问题 |

| 版本对比 | 任务详情“⑥ 结果版本” → **版本对比** | 选择两个版本，对比金额、费用明细差额、依据新增/移除与正文差异 |
| 按审核意见重跑 | 任务被退回时详情页 | 显示最近审核意见，一键带 note 重新运行 AI（历史版本保留） |
| 导出 Markdown | 结果区 **导出 Markdown** | 把当前测算说明下载为 `.md`，便于归档/贴报告 |
