## 3 接口与模块配合约定（联调依据）

| 约定 | 内容 | 责任 |
|---|---|---|
| 统一响应包 | `{code,message,data,trace_id}`，`code=0` 成功；错误码 400/401/403/404/409/429/500 全局统一 | 成员B |
| 契约来源 | 以 `BUILD_SPEC.md` §3（表）/§4（接口）/§5（工具）为唯一契约，先定契约再并行开发 | A+B |
| 模板上下文 | 页面路由传字段名固定（`task/params/materials/latest_ai/latest_result/versions` 等），前端只消费不改名 | B→C |
| AI 接口 | `POST /business-tasks/{id}/ai-tasks` 返回 202 + `ai_task_id`；前端 2s 轮询 `GET /ai-tasks/{id}`；失败显示 `error_code` + 重试按钮 | A+C |
| 执行记录字段 | `seq/tool_name/tool_type/args_json/result_summary/source_ids_json/status/error_code/latency_ms` 全字段透出 | A+C |
| 版本与审核 | 保存版本走 `POST /results`，提交走 `/submit`，审核走 `/review`；版本冻结返回 409 | B |
| 数据字段 | `content_json` 必填键见 [05 数据字典](./05_数据字典.md) §4；改格式须同步通知 A/B | D |
| 变更流程 | 契约变更先在群里同步 + 改 `BUILD_SPEC.md`，再改代码；文档与图同版本号 | 全体 |
